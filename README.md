# Salesman Dairy

সেলসম্যানের ব্যক্তিগত ব্যবহারের অফলাইন অ্যান্ড্রয়েড অ্যাপ (Flutter + SQLite)। সার্ভার বা ইন্টারনেট লাগে না।

| ফোল্ডার | কী |
|---|---|
| [`salesman_dairy/`](salesman_dairy) | **নতুন ও সর্বশেষ:** মার্কেট → আউটলেট ভিত্তিক সেলসম্যান অ্যাপ। বিক্রি, আদায়, মার্কেট বাকি, টার্গেট, অর্জন, আজকের রুট |
| [`salesman_diary/`](salesman_diary) | পুরনো প্রথম ভার্সন (আর ব্যবহার হচ্ছে না): কাস্টমার-ভিত্তিক সাধারণ সেলসম্যান ডায়েরি |

দুটো আলাদা অ্যাপ, আলাদা ডেটাবেস। সেটআপ ও চালানোর নিয়ম প্রতিটি ফোল্ডারের `README.md`-তে আছে
(`flutter create . --platforms=android` চালিয়ে Android ফাইল তৈরি করতে হবে)।
